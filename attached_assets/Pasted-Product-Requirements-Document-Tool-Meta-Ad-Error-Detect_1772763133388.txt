Product Requirements Document
Tool: Meta Ad Error Detection Scanner
Goal

Automatically scan Meta ad accounts and detect configuration errors, creative issues, AI toggles, and placement problems that negatively affect ad performance or cause broken-looking ads.

The tool flags issues and produces structured findings so the team can quickly identify and fix mistakes made during campaign setup.

System Overview
Core Components

Account Scanner
Pulls ads from Meta API for each connected account.

Creative Analyzer
Examines ad creative assets (images, videos, ratios).

Rule Engine
Runs rule checks against each ad.

Policy Layer
Client-specific rules and allowed settings.

Findings Database
Stores detected issues.

Dashboard
Shows flagged problems.

Alert System
Slack / Email alerts for severe issues.
